漢字の字の形と筆順のデータ

アプリ「中学受験ハムトレ」で使っている、小学校で習う漢字(1026 字)の、1 画ずつの字の形と筆順のデータです。

kanji_glyphs.json をダウンロード ・ ライセンス(ARPHICPL.TXT)

このデータは AnimCJK(© FM&SH。Arphic PL KaitiM GB / Big5 と Makemeahanzi をもとにしたもの)の graphicsJa.txt と、 それを小学校の形に一部直した subAnimJ をもとに、小学校で習う形に直して作りました。 元のデータと同じ Arphic Public License で提供します。同じ条件で、自由に使ったり作りかえたりできます。

変えたこと(2026 年 11 月): 1〜6 年の 1026 字だけを取り出し、一部の字は subAnimJ の形を使い、小学校で習う形に直し(枠の中の横画をのばしてとなりの画にとどかせる・画や部首をほかの字の画と入れかえる)、座標の上下を画面の向き(y = 900 - y)に直して、1 つの JSON にまとめました。

形式: glyphs に字ごとに、strokes(画ごとの輪郭。1024×1024 の中の SVG の path の d)と、 medians(画ごとの中心線。x, y, x, y, … の順)を、書く順に並べています。

Per-stroke outlines and medians for the 1,026 kanji taught in Japanese elementary school. Derived from AnimCJK (© FM&SH, based on Arphic PL KaitiM fonts and Makemeahanzi) and subAnimJ. Modified in November 2026: extracted the 1,026 characters, modified some glyphs to the forms taught in Japanese elementary school (subAnimJ glyphs used for some characters; strokes extended to touch, strokes and radicals replaced), flipped the y axis to screen coordinates (y = 900 - y) and merged them into one JSON file.
